## 📝 Contributing to Documentation

When adding new documentation:

1. **Completed Features** → `docs/completed/` (use `*_COMPLETE.md` naming)
2. **Guides/References** → `docs/guides/` (use `*_GUIDE.md`, `*_REFERENCE.md`, or `*_CHECKLIST.md`)
3. **Architecture/Planning** → `docs/architecture/` (use `ARCHITECTURE_*` or `DEVELOPMENT_*` or `DEPLOYMENT_*`)

### Naming Conventions:
- Completed: `FEATURE_NAME_COMPLETE.md`
- Guides: `FEATURE_NAME_GUIDE.md` or `FEATURE_NAME_QUICK_START.md`
- Reference: `FEATURE_NAME_REFERENCE.md` or `FEATURE_NAME_QUICK_REF.md`
- Testing: `FEATURE_NAME_TESTING_GUIDE.md`
- Checklists: `FEATURE_NAME_CHECKLIST.md`
- Status: `FEATURE_NAME_STATUS.md` or `FEATURE_NAME_PROGRESS.md`
